# 会社デモセールス議事録管理

このリポジトリは会社のデモセールスプロセスに関連する議事録をまとめ、アクセス可能な形で管理するためのものです。

## 目的

- 販売プロセスの透明性の確保
- 顧客とのコミュニケーション履歴の中央管理
- 営業チーム間の情報共有の促進
- ベストプラクティスと成功事例の文書化

## 構造

- `docs/` - 販売プロセスに関する一般的なドキュメントと手順
- `meetings/` - 議事録本体
  - `general/` - 内部ミーティングの議事録
  - `project/` - 顧客プロジェクトミーティングの議事録
- `company-profile.md` - 会社概要資料

## AI への指示

あなたは、このリポジトリに含まれるすべての議事録を分析し、情報を整理する AI アシスタントです。以下の指示に従ってください：

1. すべての議事録ファイルを読み取り、重要なポイントを抽出してください
2. 以下のカテゴリに基づいて情報を整理してください：
   - 顧客のニーズと課題
   - 提案したソリューションと価値提案
   - 決定事項とアクションアイテム
   - フォローアップすべき項目
   - セールスプロセスの段階（初期接触、要件定義、提案、交渉など）

3. 日付やプロジェクト名で整理し、時系列での進捗や変化を追跡できるようにしてください
4. 過去の類似案件との共通点や相違点を特定し、成功事例や教訓を抽出してください
5. 分析結果を要約し、販売プロセスの改善につながる洞察を提供してください

最終的な出力は、営業チームがすぐに活用できる形式で提供してください。例えば、以下のような構成が望ましいです：
- 各プロジェクトの要約（現状と今後のステップ）
- 顧客別の重要ポイントまとめ
- 発見された成功パターンや注意点
- 時系列でのプロジェクト進捗状況
